# Fonts for the card images

The site's type (DESIGN.md §3) as files, for the card images (WEB-41d, `next/og`), which can't use the web fonts
`next/font` loads. All three are under the SIL Open Font License 1.1 (each `*-OFL.txt`), which allows bundling
them with software.

| File | Font | Source |
|---|---|---|
| `Marcellus-Regular.ttf` | Marcellus 400 | google/fonts, `ofl/marcellus` |
| `MarcellusSC-Regular.ttf` | Marcellus SC 400 | google/fonts, `ofl/marcellussc` |
| `Inter-Regular.woff`, `Inter-SemiBold.woff` | Inter 400 and 600, Latin | Fontsource (`@fontsource/inter` files, static: the image renderer can't use Google's variable Inter) |
