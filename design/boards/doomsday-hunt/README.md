# Doomsday · the Hunt (DS01HuntToday, DS02HuntMore) — design reference

Design mockups from the Claude Design canvas "Doombringers v2", section "Owner · Mission pool v2 — overview, the
Hunt, PvP dailies" (WEB-110). Treat them as REFERENCE MOCKUPS, not production code: the markup and inline styles carry
the design's values, which the site replicates in its own components and tokens.

## Contents

- `DS01HuntToday.dc.html` — Today: the Hunt card (open and bagged), The Hunt today with tomorrow's quarry, Today so far;
  desktop and phone.
- `DS02HuntMore.dc.html` — the board's Hunt column, the PvP tab's Hunt trophies and Hunt · this week, the six Hunt feats.
- `support.js`, `vendor/react*.js` — the runtime that renders the boards; not part of the design.

## Viewing

`npm run design`, then open the boards from http://localhost:4400.
