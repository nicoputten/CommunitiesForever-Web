Safety rules
The owner is set on the serverOne BattleTag in the server config. The site has no button that changes, demotes or blocks the owner.
Admins can’t lock anyone outNo blocking the owner or another admin. No removing admins. No touching the bot token or uploaders of others.
Nothing silentEvery admin action goes in Admin changes, which nobody can edit or clear.
Mistakes stay smallBlocks unblock, guests re-add, runs can be re-planned. Start fresh has an Undo for 7 days and is owner only.
Hidden, not greyedOwner-only controls are left out for admins. The server checks every action again, so an old link only gets “Only the owner can do this”.
Removal is instantRemoving an admin works even while they’re signed in; their next admin click is refused.
