Tooltips & menus
  1. Hover (desktop) or tap (phone) a tree row opens its tooltip; the row gets a gold outline.
  2. Grid icon hover (B+): the talent’s name, rank and text
  3. Character name “Ada Example” is a placeholder
Window chrome (title, tabs) not listed.

Rules

Trigger: hover a tree row in the Talents box (desktop, 150 ms delay, opens to the right of the box) or tap it (phone, bottom sheet; swipe down closes). The row gets a gold outline while its tooltip is open.
A · tree only (when we only know points per tree): tree name in the class colour, “20 points”, one grey line describing the tree.
B · full (when we know the talents): name + points, then every talent with points in it, in tree order (top row first): name, rank “3/5” in gold, the talent’s text for that rank. Talents with 0 points aren’t listed. A tree with 0 points shows “0 points” and the description from A.
B+ · grid (optional): the Forever Destruction tree is 3 columns × 7 rows (16 talents, from the client, build 1.60.1). Full rank = gold border, partial = green border with the rank badge, open but empty = plain, rows not reached yet = 35 %. On desktop the grid sits left of the list (tooltip 460 px); on phone above it.
Texts come from the spell descriptions in the client; the texts on this board are illustrative. The tooltip uses the in-game look, like the item tooltip.
