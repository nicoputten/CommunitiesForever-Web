Channels
One default channel lives in The bot. Every box has its own channel picker that starts at “Default · # doombringers”, so the admin only changes the ones that should go elsewhere (runs usually do).
Time zones, three on purpose
Your time zone reads typed times (/plan 20:00).
Recap time is in the admin’s time zone, as before.
Doomsday reset is in realm time, so it is the same moment for everyone and for the addon. Each field says which clock it uses.
Jump bar
A sticky row of section chips under the title, so the admin lands on Doomsday or Runs in one tap. Friends only see the first two chips.
