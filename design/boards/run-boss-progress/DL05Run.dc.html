Rules

The run page (RunDetailV2) keeps its Group and Answers. New: a Bosses box at the top of the right column, only once the run has started (the first kill or the start time): a ✓ and the kill time per boss from the kill log of anyone in the group, “3 of 6” (required bosses only; optional ones say “optional”) and a bar. Final boss down → “Cleared · 21:24” and the run counts for “Last cleared”; an optional boss that wasn’t killed then shows “– skipped” in grey. While running, a grey “as of 20:45 · Grom’s upload” line sits under the bar, because the site only learns kills from uploads (SavedVariables are written on /reload or logout); it goes once the run is cleared. The addon itself shows kills live. Dungeon page › under the title, Loot on the dungeon page › under the bosses. Before the start the box isn’t shown. The bot doesn’t change.
