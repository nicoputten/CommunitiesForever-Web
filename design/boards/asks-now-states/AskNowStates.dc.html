Answers to the brief
1
Light theme

The site is dark only (Night over Azeroth has no light variant), so there is no light board. “Dark and light” applies to Discord, where the ask post already exists. If a light site theme is wanted later, it's a separate project.

2
Which character does I'm in use?

The same levelFit rule as Runs v2: best is fits, then +N over, then N below (1–5). A carry (10+ over) is never the default but can be picked. “change ▾” opens the v2 character & role picker without the slot status (asks have no slots).

3
When is it “none fit”?

Only when every character is 6+ below the range. If there is a carry or a 1–5 below character, I'm in stays available with that character and its tag. The brief's line is kept word for word for that case.

4
Role

Defaults to the character's role from talents; changeable in the picker. Shown in the In list only when it helps: “Grom Ashfeller 24 Warrior” (role sits on the asker line).

5
Countdown

Whole minutes rounded up (“7 min”) until 60 s, then seconds (“40 s”). The last minute turns the card and bar amber (stale token). The bar shows time left. At 0 the card collapses (160 ms, instant with reduced motion); no “ended” state, as the brief says.

6
Your own ask

The asker sees it with a “Your ask” tag and no answer buttons, just “Form the group in game”. The asker can't end it early from the site (only in game).

7
Answers from the game

In-game answers travel over Battle.net and reach the site with the next upload, so the In list can lag a minute or two. No extra label; the countdown is short anyway.

8
More than 3

Newest first, 3 cards, then “and 2 more” which expands in place. On the phone the same.

9
Placement

Inside the main column above the filter result headings, below the filter chips, so it shows regardless of the filter. “Asking now” → This week → Later → Past. The “Going right now?” panel stays in the sidebar.
